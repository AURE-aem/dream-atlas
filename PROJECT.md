# Dream Atlas — Hackathon Final Edition

## Product

- [x] Dream Atlas is the homepage and the beginning of the experience
- [x] Every preserved dream becomes an interactive star
- [x] Recurring motifs create graph connections
- [x] Durable constellations can be created and strengthened
- [x] Dream Cards provide the premium memory gallery
- [x] Dream Memory provides the focused reading experience
